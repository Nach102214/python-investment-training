* `Пробел + ff` — Быстрый поиск любого файла в проекте (`Telescope`).
* `Пробел + w` — Сохранить текущий файл (вместо `:w`).
* `Пробел + q` — Закрыть текущее окно / Выйти из Neovim.
* `Esc`         — **Сбросить подсветку поиска** (очищает желтые маркеры).
* `Tab`         — Переключиться на следующую вкладку вверху экрана.
* `Shift + Tab` — Вернуться на предыдущую вкладку.

## 🐍 Запуск Python-кода и терминал

* `Пробел + x` — **Запустить текущий Python-файл.** Код автоматически сохранится, снизу откроется терминал, выполнит скрипт, а курсор останется вверху в коде.
* `Esc`        — **Умное закрытие:** полностью уничтожает нижнее окно терминала и выгружает его из памяти.
* `Пробел + tc` — Альтернативная команда для закрытия и выгрузки терминала.
* `В терминале: Esc` — Переводит терминал в Normal-режим (можно скроллить вывод стрелками).
* `Ctrl + ↑ / ↓ / ← / →` — **Быстрая навигация:** мгновенно перемещает курсор между разделенными окнами.

## 🛠️ Отладка кода (DAP по кнопке F5)

1. Наведите курсор на строку, где хотите поставить паузу, и нажмите `Пробел + b`.
2. Нажмите `F5` для старта. Экран разделится на панели отладчика.
3. **Если программа просит ввод (`input()`):** перейдите в нижний терминал (`Ctrl + ↓`), нажмите `i`, введите данные, `Enter`. Затем `Esc`, `Ctrl + \` `Ctrl + n`, `Ctrl + ↑` — вернуться к коду.

* `F5`          — Запустить отладку / Продолжить движение до следующей точки.
* `F10`         — Сделать шаг вперед (выполнить следующую строчку кода).
* `F11`         — Шагнуть внутрь функции (если курсор стоит на её вызове).
* `F12`         — Шагнуть наружу из функции.
* `Пробел + b`  — Поставить или снять точку останова (Breakpoint).
* `Пробел + dr` — Перезапустить сессию отладки с самого начала.
* `Пробел + dt` — **Остановить (terminate) зависшую сессию отладки.** Спасает, если попали в бесконечный цикл.
* `Пробел + du` — **Toggle DAP UI** — скрыть/показать панели отладчика (Locals, Watches, Console).

# 🔹 ЧАСТЬ 5: РЕКОМЕНДАЦИИ ОТ ИИ

1. **Разделяйте обязанности Tmux и Neovim:**
   Не нужно плодить панели в Tmux, если вам просто нужно запустить Python-код. Пользуйтесь вашим встроенным `<leader>x`. Tmux используйте для глобальных задач: в одном окне Tmux запущен Neovim с учёбой, во втором окне Tmux — системные утилиты (например, `htop` или менеджер пакетов `pip`), в третьем — Git.

2. **Не закрывайте Neovim без необходимости:**
   Благодаря Tmux вы можете отключиться от сессии (нажав `Ctrl+b`, затем `d`), закрыть терминал ноутбука, уйти спать, а утром открыть терминал, написать `tmux a`, и вернуть весь ваш рабочий процесс ровно на том символе, где вы остановились.

3. **Используйте отладчик (`F5`) вместо `print()`:**
   Когда вы учитесь работать со строками и списками, вместо постоянного написания `print(переменная)`, ставьте точку останова через `<leader>b` на сложной строке и запускайте `F5`. Боковое меню переменных покажет вам состав вашей строки/списка в тысячу раз нагляднее.

4. **Вводите данные в DAP через терминал:**
   При отладке программ с `input()` приглашение появляется в **нижнем терминале**, а не в окне кода. Перейдите туда (`Ctrl + ↓`), нажмите `i`, введите данные, `Enter`. Вернитесь к коду (`Ctrl + ↑`).

5. **Ведите раздел «Мои ошибки»:**
   Когда наткнётесь на что-то, что долго искали — запишите сюда. Через месяц это будет ваша **личная** шпаргалка.

# 🔹 ЧАСТЬ 6: КОДИРОВКИ И BOM

## 📄 Что такое BOM

**BOM** (Byte Order Mark) — это специальная последовательность из 3 байтов (`EF BB BF`) в начале файла, которая говорит программам: «этот файл в UTF-8».

**На Linux** BOM **не нужен** и часто **вредит**:
- Python-скрипты падают с `SyntaxError`.
- Shell-скрипты не работают (`#!/bin/bash` не распознаётся).
- Git показывает «изменение первой строки» без причины.

**На Windows** BOM помогает «Блокноту» и Excel правильно определить кодировку.

## ⚙️ Как настроено у меня

В `init.lua`:
```lua
vim.opt.encoding = "utf-8"
vim.opt.fileencodings = "ucs-bom,utf-8,cp1251,koi8-r,cp866,latin1"
vim.opt.bomb = false
