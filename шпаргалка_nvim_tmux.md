# 🔹 ЧАСТЬ 1: БАЗОВЫЙ NEOVIM (работает везде)

> 💡 Это стандартные команды Vim/Neovim. Они работают в **любой** консоли, на **любом** компьютере,
> даже без твоего `init.lua`. Учи их в первую очередь.

---

## 🧭 Движение по файлу (Normal mode)

* `h j k l`       — Влево, вниз, вверх, вправо (вместо стрелок)
* `w` / `b`       — Вперёд / назад на одно слово
* `e`             — К концу слова
* `0` / `$`       — В начало / конец строки
* `gg` / `G`      — В начало / конец файла
* `Ctrl + d` / `Ctrl + u` — Прокрутка вниз / вверх на пол-экрана
* `Ctrl + f` / `Ctrl + b` — Прокрутка вниз / вверх на целый экран
* `:12`           — Перейти на строку 12
* `%`             — Прыгнуть к парной скобке `( ) { } [ ]`
* `{` / `}`       — Прыжок на абзац вверх / вниз

---

## ✏️ Редактирование (Normal mode)

* `i` / `a`       — Войти в режим вставки **перед** / **после** курсора
* `I` / `A`       — Вставка в начало / конец строки
* `o` / `O`       — Новая строка **ниже** / **выше** и режим вставки
* `dd`            — Удалить строку
* `yy`            — Скопировать строку
* `p` / `P`       — Вставить **после** / **перед** курсором
* `ciw`           — Заменить слово под курсором (change inner word)
* `ci"`           — Заменить текст внутри кавычек
* `di(`           — Удалить текст внутри скобок
* `>>` / `<<`     — Сдвинуть строку вправо / влево (отступ)
* `v`             — Визуальный режим (символьное выделение)
* `V`             — Визуальный режим (построчное выделение)
* `Ctrl + v`      — Блочное выделение (колонка)
* `r`             — Заменить один символ под курсором
* `x`             — Удалить один символ под курсором

## 🔍 Поиск и замена

* `/слово`        — Поиск вперёд
* `?слово`        — Поиск назад
* `n` / `N`       — Следующее / предыдущее совпадение
* `*`             — Найти слово под курсором вперёд
* `#`             — Найти слово под курсором назад
* `:%s/старое/новое/g` — Заменить во всём файле
* `:s/старое/новое/g`  — Заменить в текущей строке
* `:%s/старое/новое/gc` — Заменить с подтверждением каждого

---

## 💾 Файлы

* `:w`            — Сохранить изменения
* `:q`            — Выйти (если нет изменений)
* `:wq`           — Сохранить и выйти
* `:q!`           — Выйти без сохранения
* `:e файл.py`    — Открыть другой файл
* `:saveas новый.py` — Сохранить как
* `:e!`           — Перезагрузить файл с диска (отменить несохранённые изменения)

## 📐 Отступы (важно для Python)

* `>>` / `<<`     — Сдвинуть строку вправо / влево
* `>` / `<` (в Visual) — Сдвинуть выделенный блок
* `:set tabstop=4` — Установить размер таба (в Python — 4)
* `:set expandtab` — Заменять табы пробелами
* `gg=G`          — Автоматически выровнять отступы во всём файле
* `=` (в Visual)  — Выровнять отступы выделенного блока

# 🔹 ЧАСТЬ 2: МОЙ КОНФИГ NEOVIM (`init.lua`)

> 💡 **ВАЖНО:** Клавиша `<leader>` в моих настройках — это **ПРОБЕЛ**.
> Нажимайте Пробел, отпускайте его, а затем сразу нажимайте нужную букву.
> Эти команды работают **только на моём ноутбуке**.

---

## 📁 Управление файлами и буферами (Вкладками)

* `Пробел + e`  — Открыть / закрыть дерево файлов (`NvimTree`) слева.
* `Пробел + ff` — Быстрый поиск любого файла в проекте (`Telescope`).
* `Пробел + w`  — Сохранить текущий файл (вместо `:w`).
* `Пробел + q`  — Закрыть текущее окно / Выйти из Neovim.
* `Esc`          — **Умное действие:** Закрывает терминал, если он открыт, ИЛИ сбрасывает подсветку поиска (очищает маркеры).
* `Tab`          — Переключиться на следующую вкладку (буфер) вверху экрана.
* `Shift + Tab`  — Вернуться на предыдущую вкладку (буфер).
* `Alt + 1...3`  — Перепрыгнуть на вкладку под номером 1, 2 или 3.
* `Alt + ←` / `Alt + →` — Листать вкладки (буферы) назад и вперед.
* `Alt + w`      — **Закрыть текущую вкладку** (`bdelete`) без поломки сетки окон.

---

## 🐍 Запуск Python-кода, Терминал и Markdown

* `Пробел + x`  — **Умный запуск кода:** Автоматически сохраняет файл. Если открыт `.py` — запускает его в терминале снизу. Если открыт `.md` — вытаскивает блоки ` ```python `, сохраняет во временный файл и интерактивно запускает снизу!
* `Пробел + tc` — Принудительно закрыть нижнее окно терминала и выгрузить буфер из памяти.
* `В терминале: Esc` — Переводит терминал в Normal-режим (позволяет копировать вывод или скроллить его).
* `Ctrl + ↑ / ↓ / ← / →` — **Быстрая навигация:** Шагнуть курсором в окно сверху, снизу, слева или справа (работает в Normal и Visual).
* `Пробел + mk` — **Предпросмотр Markdown:** Включает/выключает отображение вашего конспекта и схем Mermaid прямо в браузере.

---

## 📝 Запуск кусков кода "на лету" (SnipRun)

* `Пробел + sr` — (В режиме **NORMAL**): Запускает текущую строку кода.
* `Пробел + sr` — (В режиме **VISUAL**, выделив блок строк): Запускает выделенный код в фоновом режиме и выводит результат справа виртуальным текстом.
* `Пробел + sc` — Очистить результаты выполнения `SnipRun` на экране.

---

## 🛠️ Отладчик кода (DAP)

1. Наведите курсор на строку, где хотите поставить паузу, и нажмите `Пробел + b`.
2. Нажмите `F5` для старта. Экран разделится на панели отладчика (DAP UI).
3. Если программа просит ввод (`input()`), перейдите в терминал отладки.

* `F5`          — Запустить отладку / Продолжить движение до следующей точки останова.
* `F10`         — Сделать шаг вперед без захода внутрь функций (`step over`).
* `F11`         — Шагнуть внутрь функции (`step into`).
* `F12`         — Шагнуть наружу из функции (`step out`).
* `Пробел + b`  — Поставить или снять точку останова (Breakpoint).
* `Пробел + dr` — Перезапустить сессию отладки с самого начала.
* `Пробел + dt` — **Остановить (terminate) зависшую сессию отладки**.
* `Пробел + du` — Переключить видимость панелей отладчика (скрыть/показать DAP UI).

## 🌐 Комментирование, Переводчик и Линтеры (Ruff / Pyright)

* `g c c`       — **Закомментировать / раскомментировать строку** (в Normal режиме).
* `g c`         — (В режиме выделения `v` или `V`): **Закомментировать выделенный блок**.
* `g l`         — Показать системное плавающее окно с полным текстом ошибки (LSP).
* `]d` / `[d`   — Прыгнуть к следующей / предыдущей ошибке линтера в файле.
* `Пробел + dl` — Открыть нижний список всех обнаруженных ошибок в текущем файле.
* `Пробел + fm` — Автоматически форматировать код в файле (исправление отступов по PEP8 через Ruff/Pyright).
* `Пробел + t`  — (В Normal): Показать перевод слова под курсором во всплывающем окне.
* `Пробел + t`  — (В Visual): Показать перевод выделенного участка текста.
* `Пробел + r`  — (В Normal): Перевести слово под курсором и **сразу заменить его** результатом.
* `Пробел + r`  — (В Visual): Перевести выделенный текст и **заменить его** переводом.
* `Пробел + gt` — **Перевести текст текущей ошибки линтера** под курсором на русский язык.

## 🐍 LSP: Навигация по функциям и классам

* `K`            — Показать документацию и параметры функции под курсором во всплывающем окне.
* `gd`           — Перейти к определению функции или класса (Go to definition).
* `gr`           — Найти все места в проекте, где используется эта функция (Go to references).
* `gI`           — Перейти к реализации (Go to implementation).
* `Пробел + ca`  — Показать доступные быстрые действия кода (Code Actions).

# 🔹 ЧАСТЬ 3: TMUX (стандартный набор)

> 💡 Любая команда в Tmux начинается с префикса **`Ctrl + b`**.
> Сначала зажмите `Ctrl` и нажмите `b`, затем отпустите их и нажмите следующую клавишу.

## 🪟 Разделение экрана на панели (Panes)

* `Ctrl+b` затем `%` — Разделить экран вертикально (левая и правая части).
* `Ctrl+b` затем `"` — Разделить экран горизонтально (верхняя и нижняя части).
* `Ctrl+b` затем `o` — Перепрыгнуть в следующую панель по кругу.
* `Ctrl+b` затем `x` — Закрыть текущую панель (требует подтверждения `y`).
* `Ctrl+b` затем `z` — Развернуть панель на весь экран (повторное нажатие сворачивает обратно).
* `Ctrl+b` затем `←↑→↓` — Переход между панелями с помощью стрелок.

## 📑 Управление окнами-вкладками (Windows)

• Ctrl+b затем c — Создать новое чистое окно (вкладку на нижней панели).
• Ctrl+b затем n — Перейти на следующее окно.
• Ctrl+b затем p — Перейти на предыдущее окно.
• Ctrl+b затем 0...9 — Прыгнуть на окно по его порядковому номеру.
• Ctrl+b затем w — Вывести интерактивное дерево всех окон и панелей.
• Ctrl+b затем , — Переименовать текущее окно.

## 💤 Отключение и возврат к сессии

• Ctrl+b затем d — Отключиться от сессии (все процессы продолжат выполняться в фоне).
• tmux a         — Вернуться к последней активной сессии в терминале.
• tmux ls        — Показать список всех запущенных сессий в фоне.
• tmux new -s имя — Создать новую изолированную сессию с конкретным именем.
• tmux a -t имя  — Подключиться к сессии с выбранным именем.

# 🔹 ЧАСТЬ 5: РЕКОМЕНДАЦИИ ОТ ИИ

1. Используйте разделение сред:
Tmux идеален для долгоживущих процессов (запуск торгового робота, фоновые логи, системные утилиты htop). Для проверки кода питона и конспектов во время учебы используйте встроенную кнопку <leader>x, которая не плодит лишних вкладок в Tmux.
2. Не закрывайте Neovim без необходимости:
Благодаря связке с Tmux вы можете нажать Ctrl+b, затем d, закрыть терминал или крышку ноутбука, а на следующий день написать tmux a и продолжить работу ровно с того же символа.
3. Для интерактивных скриптов используйте <leader>x:
Если в коде есть циклы while True и функции input(), плагин SnipRun вернет no output. Для таких задач всегда нажимайте Пробел + x, чтобы работать в полноценном интерактивном терминале снизу.

# 🔹 ЧАСТЬ 6: КОДИРОВКИ И BOM

📄 Специфика BOM (Byte Order Mark)

BOM — последовательность байтов (EF BB BF) в начале файла.
• На Linux она отключена (vim.opt.bomb = false), так как вызывает синтаксические ошибки в скриптах Python и ломает историю коммитов Git.
• На Windows она помогает старым редакторам распознать UTF-8.
В текущем init.lua настроено автоматическое чтение кодировок: ucs-bom,utf-8,cp1251,koi8-r,cp866,latin1.
