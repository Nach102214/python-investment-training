# Python Investment Training

Учебный проект по изучению Python с уклоном в анализ данных и инвестиции.

## О проекте

Это мой путь от нуля до уверенного программиста на Python. Цели:
- Анализ брокерских отчётов (HTML, CSV)
- Автоматизация расчётов по портфелю
- Визуализация данных
- Возможная подработка в анализе данных или QA

## Структура

- `Practice/Matthes/` — практика по книге «Изучаем Python» Эрика Мэтиза
- `Practice/OOP_Book/` — практика по книге «ООП на Python с нуля»
- `Practice/Algorithms/` — практика по книге «Алгоритмы и структуры данных»
