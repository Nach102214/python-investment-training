## 📜 Правила курса

1. **Один модуль — одна тема.** Не перескакиваем.
2. **Сначала решаем — потом смотрим.** Никаких `solutions/` до попытки.
3. **Объясняй каждую строку.** Если не можешь — тема не усвоена.
4. **Mermaid обязателен** для задач с 💡 (алгоритмические).
5. **Терминал — друг.** Запуск: `<leader>x` в Neovim или `python3 file.py`.
6. **Ошибки — это норма.** Читаем traceback снизу вверх.
