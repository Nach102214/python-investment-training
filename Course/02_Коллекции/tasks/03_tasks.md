## 🟡 B. Практика

**B1.** Пользователь вводит тикер в **любом регистре** (`"sber"`, `"SBER"`, `"SbEr"`). Приведи к верхнему регистру и выведи: `"Тикер: SBER"`.

**B2.** Пользователь вводит строку с лишними пробелами по краям: `"   SBER   "`. Убери их через `.strip()` и выведи: `"<SBER>"` (с угловыми скобками, чтобы видеть, что пробелов нет).

**B3.** Есть строка `"apple,banana,cherry,date"`. Разбей её через `.split(",")` и выведи **каждый элемент с новой строки** (можно через `for`, но пока можно и через `print(*lst, sep="\n")`).

**B4.** Обратная задача: есть список `["SBER", "GAZP", "LKOH"]`. Склей через `"|".join(...)` в строку `"SBER|GAZP|LKOH"`.

**B5.** 💡 Пользователь вводит путь к файлу, например `"/home/nach101/report.csv"`. Выведи:
- имя файла (`"report.csv"`)
- расширение (`"csv"`)
- имя без расширения (`"report"`)
- каталог (`"/home/nach101"`)

**Подсказка:** `.split("/")`, `.rsplit(".", 1)`, `"/".join(...)`.
**Нарисуй схему в `Mermaid/B05.md`.**

**B6.** Пользователь вводит сумму как строку: `"12 345.67"`. Убери пробел и приведи к `float`. Выведи результат с типом.
