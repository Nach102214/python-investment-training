# 03. Строки (str)

## Что такое строка
Строка — **неизменяемая** последовательность символов Unicode.
```python
s = "SBER"
t = 'AAPL'
u = """Многострочная
строка"""
```

## Индексация (с нуля!)
```python
s = "SBER"
#    S  B  E  R
#    0  1  2  3
#   -4 -3 -2 -1

s[0]    # 'S'
s[-1]   # 'R'  (последний)
s[10]   # ❌ IndexError
```

## Срезы (slicing) — `[start:stop:step]`
```python
s = "SBERGAZP"
s[0:4]    # 'SBER'   (start=0, stop=4, не включая 4)
s[:4]     # 'SBER'   (start по умолчанию 0)
s[4:]     # 'GAZP'   (stop по умолчанию len)
s[:]      # 'SBERGAZP' (копия)
s[::2]    # 'SEGP'   (каждый второй)
s[::-1]   # 'PZAGREBS' (разворот!)
s[-4:]    # 'GAZP'   (последние 4)
```

## Неизменяемость
```python
s = "SBER"
s[0] = "X"    # ❌ TypeError
s = "XBER"    # ✅ переприсваивание — ок
```

## Основные методы
|  Метод            | Что делает                | Пример                                |
|-------------------|---------------------------|----------------------------------------
| `s.upper()`       | ВЕРХНИЙ РЕГИСТР           | `"sber".upper()` → `"SBER"`           |
| `s.lower()`       | нижний регистр            | `"SBER".lower()` → `"sber"`           |
| `s.strip()`       | обрезать пробелы по краям | `"  x  ".strip()` → `"x"`             |
| `s.split(sep)`    | разбить на список         | `"a,b,c".split(",")` → `['a','b','c']`|
| `",".join(lst)`   | склеить список            | `",".join(['a','b'])` → `"a,b"`       |
| `s.replace(a, b)` | заменить                  | `"SBER".replace("S","X")` → `"XBER"`  |
| `s.find(sub)`     | индекс подстроки или -1   | `"SBER".find("BE")` → `1`             |
| `s.startswith(p)` | начинается с?             | `"SBER".startswith("SB")` → `True`    |
| `s.endswith(p)`   | кончается на?             | `"SBER".endswith("ER")` → `True`      |
| `s.count(sub)`    | сколько раз встречается   | `"SBER".count("S")` → `1`             |
| `s.isdigit()`     | все символы — цифры?      | `"100".isdigit()` → `True`            |

## Форматирование
```python
ticker = "SBER"
price = 250.75
shares = 100

print(f"Тикер: {ticker}, цена: {price:.2f}, кол-во: {shares}")
# Тикер: SBER, цена: 250.75, кол-во: 100
```

## Конкатенация
```python
"a" + "b"       # "ab"
"a" * 3         # "aaa"
"5" + 5         # ❌ TypeError
str(5) + "5"    # "55"  (явное приведение)
```

## Кодировка (важно для отчётов брокера!)
```python
"Привет".encode("utf-8")   # b'\xd0\x9f...'
b'\xd0\x9f...'.decode("utf-8")  # "Привет"
```
Брокерские отчёты часто в **cp1251** — на модуле 05 разберём.

## Что нужно запомнить
1. **Индексы с 0**, отрицательные — с конца.
2. **Срезы**: `[start:stop]` — `stop` **не включается**.
3. **Строки неизменяемы**: нельзя `s[0] = "X"`, но можно `s = s.replace(...)`.
4. **f-strings** — твой главный инструмент.
5. **`.split()` / `.join()`** — рабочая лошадка парсинга.
