# 01. Переменные и типы данных

## Что такое переменная?
Переменная — это **имя**, за которым стоит **значение**. В Python не нужно
объявлять тип — он определяется автоматически.

```python
x = 42          # int
price = 99.90   # float
name = "AAPL"   # str
active = True   # bool
# 4 базовых типа

    Тип	    Пример	    Назначение
    int	    100, -5	    целые числа
    float	3.14, 99.9	числа с точкой
    str	    "AAPL"	    строка (текст)
    bool	True, False	 логика

# Как узнать тип?

    type(42)      # <class 'int'>
    type("AAPL")  # <class 'str'>
