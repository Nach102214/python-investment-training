# Глава 5. Оператор if

## 📖 Что изучали
Условные операторы: `if`, `if-else`, `if-elif-else`, проверки условий,
логические операторы, использование `if` со списками.

## 🎯 Ключевые концепции
- Операторы сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Логические операторы: `and`, `or`, `not`
- Проверка вхождения: `in`, `not in`
- Цепочка: `if-elif-else`
- Проверка пустого списка: `if list:`
- Логические значения: `True`, `False`

## 💡 Главное, что я понял
- **Приоритет `and` > `or`**. Всегда ставлю **скобки** при смешивании
- **Цепочка `if-elif-else`** — для **взаимоисключающих** условий
- **Отдельные `if`** — для **независимых** проверок
- **`if list:`** — идиоматичная проверка «список не пуст»
- **Отступы** в Python **обязательны** и **значимы**
- **`else` можно опустить** — если есть завершающий `elif` с конкретным условием

## ⚠️ Подводные камни
- `=` (присваивание) vs `==` (сравнение) — **частая** ошибка
- `if x == 2 or 3:` — **не работает** как ожидается. Нужно: `if x == 2 or x == 3:`
- Пропущенное **двоеточие** в `if` → `SyntaxError`
- **Лишний отступ** после `if` → `IndentationError`
- Проверка регистра: `'BMW' != 'bmw'`. Для сравнения — `.lower()`
