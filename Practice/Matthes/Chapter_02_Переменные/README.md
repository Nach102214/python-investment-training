# Глава 2. Переменные и простые типы данных

## 📖 Что изучали
Переменные, строки, числа, комментарии. Разница между `int` и `float`,
методы строк, f-строки, Дзен Python.

## 🎯 Ключевые концепции
- Переменная как «метка» на объект (а не «ящик»)
- Типы данных: `int`, `float`, `str`
- f-строки: `f"{переменная}"`
- Методы строк: `.title()`, `.upper()`, `.lower()`, `.strip()`, `.rstrip()`, `.lstrip()`, `.removeprefix()`
- Пробельные символы: `\t` (табуляция), `\n` (перевод строки)
- Комментарии: `#`
- Константы: `MAX_CONNECTIONS = 5000`

## 💡 Главное, что я понял
- Переменная — это **метка**, а не «ящик». Важно для понимания ссылок.
- f-строки — самый удобный способ вставки переменных в текст.
- `.strip()` незаменим для очистки пользовательского ввода.
- Разница между `int` и `float`: `4/2 = 2.0` (всегда float при делении).
- Комментарии важнее, чем кажется. Пишу их для **будущего себя**.

## ⚠️ Подводные камни
- Забыл `f` перед строкой → переменная не подставится
- Кавычки внутри f-строки: **внешние** и **внутренние** должны быть **разными**
- `.capitalize()` «прибивает» остальные буквы — использовать с осторожностью
- Ошибки округления: `0.1 + 0.2 = 0.30000000000000004`
