# Глава 7. Ввод данных и циклы while

## 📖 Что изучали
Ввод данных от пользователя через `input()`, цикл `while`, флаги, `break`,
`continue`, использование `while` со списками и словарями.

## 🎯 Ключевые концепции
- `input()` — всегда возвращает **строку**
- `int()`, `float()` — преобразование ввода
- `while условие:` — цикл с проверкой **перед** телом
- **Три способа выхода:**
  1. Условие в `while` (простой случай)
  2. Флаг (`active = False`)
  3. `break` (**основной** способ)
- `continue` — пропустить остаток тела, **не выходя** из цикла
- **`while` + список:** `.pop()` + `.append()` для переноса
- **`while` + словарь:** опрос с накоплением

## 💡 Главное, что я понял
- **`input()` возвращает строку.** Для чисел — `int()` или `float()`
- **Порядок проверок:** сначала **выход**, потом **валидация**
- **`break` — самый удобный** способ выхода. `while True:` + `break` читается сверху вниз
- **Флаг** — когда выходов **несколько**
- **`continue`** — для пропуска **одной** итерации
- **`.isdigit()`** — грубая проверка. Не пропускает `-`, `.`, `abc`. Для `float` нужен `try/except` (Глава 10)
- **`.strip()`** — обязательная привычка при работе с вводом

## ⚠️ Подводные камни
- Забыл **инициализировать** переменную до `while` → `NameError`
- Забыл **обновить** переменную внутри цикла → **бесконечный цикл** (`Ctrl+C` для выхода)
- **`.isdigit()` перед проверкой `quit`** → пользователь не сможет выйти
- **Переменные «протекают»** между задачами в одном файле
- **Падежи** в русском: Python не умеет склонять. Меняю формулировку
- **`ValueError`** при `int("abc")` — обрабатывается в Главе 10
