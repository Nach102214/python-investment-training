# Глава 3. Списки

## 📖 Что изучали
Списки: создание, доступ к элементам, изменение, добавление, удаление,
сортировка, длина.

## 🎯 Ключевые концепции
- Создание списка: `[1, 2, 3]`
- Индексация: `list[0]`, `list[-1]`
- Добавление: `.append()`, `.insert()`
- Удаление: `del`, `.pop()`, `.remove()`
- Сортировка: `.sort()`, `sorted()`, `.reverse()`
- Длина: `len(list)`
- **IndexError** — выход за границы

## 💡 Главное, что я понял
- Индексация начинается **с нуля**, а не с единицы
- `.pop()` **возвращает** удалённый элемент, `del` — нет
- `.sort()` меняет список **навсегда**, `sorted()` — **возвращает** новый
- `list[-1]` — надёжный способ получить **последний** элемент
- `IndexError` — частая ошибка. Решается через `len()` и проверки

## ⚠️ Подводные камни
- `a = b` **не копирует** список, а **ссылается** на тот же объект
- `.remove()` удаляет **только первое** вхождение
- Смешение типов: `[1, "text", 3.5]` — **можно**, но осторожно
- `list[10]` в списке из 3 элементов → `IndexError`
