# Глава 6. Словари

## 📖 Что изучали
Словари: создание, доступ, изменение, удаление, перебор. Вложенные структуры:
список словарей, словарь списков, словарь словарей. **Группировка данных** — ключевой паттерн.

## 🎯 Ключевые концепции
- Создание: `{"key": "value"}`
- Доступ: `dict["key"]`, безопасный — `dict.get("key", default)`
- Перебор: `.items()`, `.keys()`, `.values()`
- **Паттерн группировки:** пустой словарь + цикл + проверка `if key in dict`
- **Список словарей** — портфель акций
- **Словарь словарей** — быстрый поиск по тикеру
- **Группировка по ключу** — суммы по секторам

## 💡 Главное, что я понял
- **`.get()`** — безопасный доступ. Использую **всегда**, где может не быть ключа
- **Паттерн группировки:**
  ```
  dict = {}
  for item in items:
      key = item["field"]
      value = item["other"]
      if key in dict:
          dict[key] += value
      else:
          dict[key] = value
  ```
- **Порядок пар в словаре** — сохраняется с Python 3.7
- **Список словарей** — основной паттерн для **портфеля акций**
- **Словарь словарей** — быстрый доступ по ключу (тикеру)
- **`if dict:`** — проверка «словарь не пуст»

## ⚠️ Подводные камни
- `dict["missing"]` → `KeyError`. Используй `.get()`
- **Путаница** `sector` vs `sectors` (единственное/множественное)
- **`cost` vs `total_cost`** — логическая ошибка. Легко перепутать
- **f-строки** с двойными кавычками внутри — не универсально. Используй **одинарные** внутри
- **Ссылка vs копия** словаря — как со списками. `.copy()` — поверхностная
