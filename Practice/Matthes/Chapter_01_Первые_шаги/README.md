# Глава 1. Первые шаги

## 📖 Что изучали
Установка Python и VS Code, запуск первой программы `hello_world.py`,
базовые команды терминала для запуска Python-скриптов.

## 🎯 Ключевые концепции
- Установка Python из официального дистрибутива (python.org)
- Установка VS Code + расширение Python
- Запуск Python-файла через VS Code (Ctrl+F5)
- Запуск Python-файла из терминала (`python3 hello_world.py`)
- Терминальный сеанс Python (REPL) — приглашение `>>>`

## 📁 Файлы главы
| Файл | Что делает |
|------|-----------|
| `01_hello_world.py` | Выводит `Hello Python world!` |

## 💡 Главное, что я понял
- Python-файл имеет расширение `.py`
- Программы в VS Code запускаются через `Ctrl+F5`
-- Я использую в качестве IDLE neovim с настроенным конфигом
- В терминале — команда `python3 имя_файла.py`
- `print()` выводит текст на экран
- Строки заключаются в кавычки

## ⚠️ Подводные камни
- Забыть сохранить файл перед запуском
- Опечатка в `print` → `NameError`
- Отсутствие кавычек → `SyntaxError`
