# Глава 4. Работа со списками

## 📖 Что изучали
Перебор списков через `for`, числовые списки через `range()`, генераторы
списков, срезы, копирование, кортежи, форматирование кода (PEP 8).

## 🎯 Ключевые концепции
- Цикл `for element in list:`
- Функция `range(start, stop, step)`
- Генератор списка: `[x**2 for x in range(10)]`
- Срезы: `list[start:stop:step]`
- Копирование: `list[:]` (создаёт **новый** список)
- Кортеж: `(1, 2, 3)` — **неизменяемый**
- PEP 8: отступы 4 пробела, длина строки ≤ 79 символов

## 💡 Главное, что я понял
- **`list[:]`** — единственный безопасный способ **скопировать** список
- **`a = b`** — это **ссылка**, а не копия. Изменение `a` меняет `b`
- Генератор списка читается **слева направо**: `выражение → for → условие`
- **Тернарный оператор** работает только для **двух** исходов. Для 3+ — `if/elif/else`
- **Кортеж** — неизменяемый список. Защита от случайных изменений
- **PEP 8** — стандарт стиля. Соблюдать **с самого начала**

## ⚠️ Подводные камни
- `a = b` **не копирует** список — частая ошибка новичка
- `[:]` создаёт **поверхностную** копию — вложенные списки **не копируются**
- `list[1:]` — срез **до конца**, а не до второго элемента
- Забыть `,` в кортеже из одного элемента: `(5,)`, а не `(5)`
- Смешение `if/elif` и тернарного оператора → плохо читается
