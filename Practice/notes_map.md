🗺️ Кратко о функции map()

Функция map(функция, итерируемый_объект) автоматически применяет указанную функцию к каждому элементу последовательности (например, к списку строк, полученных после .split()).
• Как это работает: Строка "10 20" превращается в список строк ['10', '20']. Функция map(int, ...) берет каждый элемент и делает из него число: 10 и 20.
• Плюс: Самый быстрый и лаконичный способ преобразования типов «в одну строку».


📝 Альтернативные способы ввода (для шпаргалки)

1. Списочное включение (List Comprehension)
Самая популярная и «питоническая» альтернатива map(). Она более наглядна, если нужно выполнить дополнительное действие с элементами.
# Чтение нескольких чисел в список
numbers = [int(x) for x in input("Введите числа: ").split()]

# Чтение в отдельные переменные
a, b = [int(x) for x in input("Два числа: ").split()]

2. Классический цикл for (Пошаговый способ)
Подходит для новичков. Код длиннее, но в нем проще разобраться или добавить сложные условия валидации.
# Создаем пустой список и наполняем его в цикле
numbers = []
for x in input("Введите числа: ").split():
    numbers.append(int(x))

3. Построчный ввод (Каждое значение с новой строки)
Используется, когда данные вводятся не в ряд, а по очереди через клавишу Enter.
python
# Если заранее знаем количество переменных
a = int(input("Введите a: "))
b = int(input("Введите b: "))

4. Быстрый ввод для олимпиадного программирования (sys.stdin)
Если в задаче нужно моментально считать огромный объем данных, стандартный input() может работать медленно.

import sys

# Быстрое чтение строки чисел
a, b = map(int, sys.stdin.readline().split())
