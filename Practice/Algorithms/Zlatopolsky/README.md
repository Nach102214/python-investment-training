## 💡 Ключевые идеи

### Раздел 1. Какая программа лучше?
- **Принцип KISS** — «Keep It Simple, Stupid». Пиши проще, пока не доказано обратное.
- Три показателя программы конфликтуют: **размер**, **скорость**, **понятность**.
- Для начинающего — **понятность важнее всего**.
- Существует три способа решения одной задачи (на примере НОД):
  1. Перебор (KISS, самый понятный, но медленный)
  2. Алгоритм Евклида (быстрый, элегантный)
  3. Оптимизированный Евклид (самый быстрый, требует размышлений)

**Вывод для финансового программирования:**
В скриптах для анализа брокерских счетов важнее надёжность и читаемость, 
чем экономия миллисекунд. KISS — наш выбор.

## 📌 Правила именования файлов

- `NN_описание.py` — `NN` это номер задачи или порядковый номер файла в главе.
- Пример: `01_nod_simple.py`, `02_nod_euclid.py`
- Если задача имеет несколько вариантов решения — нумеруем их внутри имени: `01a_`, `01b_`.
