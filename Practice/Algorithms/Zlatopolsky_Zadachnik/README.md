## Формат
Каждая задача: `Task_N_MM/` с файлами:
- `algorithm.md` — условие, словесный алгоритм, блок-схема Mermaid
- `solution_v1.py`, `solution_v2.py`, ... — альтернативные решения
- `notes.md` — рефлексия, что нового узнал
