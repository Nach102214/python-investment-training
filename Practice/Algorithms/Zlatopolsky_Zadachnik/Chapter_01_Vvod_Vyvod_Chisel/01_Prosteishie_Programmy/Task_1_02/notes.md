# Заметки по задаче 1.2

## Что изучил
- Два способа импорта: `import math` vs `from math import e`
- `.1f` — один знак после запятой (для десятых)
- `round(e, 1)` возвращает число, `.1f` возвращает строку

## Сравнение решений
| Версия | Метод | Плюсы | Минусы |
|--------|-------|-------|--------|
| v1 | `from math import e` + `.1f` | коротко | не видно источник |
| v2 | `round(e, 1)` | возвращает число | теряет trailing zero |

## Вопросы / сомнения
- Когда предпочитать `import math` vs `from math import e`?

**Правило:** в коротких скриптах — оба ок. В больших проектах — import math 
             предпочтительнее (явность важнее краткости).
