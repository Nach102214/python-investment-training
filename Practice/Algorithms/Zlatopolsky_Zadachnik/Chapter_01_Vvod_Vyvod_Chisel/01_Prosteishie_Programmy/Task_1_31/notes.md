- Новый метод ввода:
-- numbers = [int(x) for x in input("Введите числа: ").split()]

#### Ошибки

Первоначально использовал не верную формулу вычисления среднего геометрического:
geometric_mean = math.sqrt(math.prod(numbers)) - она верна только для ***двух*** чисел

Если чисел больше или меньше, то по правилам математики нужно извлекать корень n-й степени, где n — это количество чисел в списке. Правильно так:
geometric_mean = math.prod(numbers) ** (1 / len(numbers))
