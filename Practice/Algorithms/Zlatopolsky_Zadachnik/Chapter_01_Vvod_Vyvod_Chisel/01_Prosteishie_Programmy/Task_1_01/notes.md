# Заметки по задаче 1.1

## Что изучил
- Разница между f-строкой `.2f` и функцией `round()`:
  - `.2f` — форматирование вывода (число остаётся полным)
  - `round(x, 2)` — изменение самого значения
- `format()` — устаревший, но встречается в старых проектах

## Сравнение решений
| Версия | Метод | Плюсы | Минусы |
|--------|-------|-------|--------|
| v1 | f-строка `.2f` | современно, читаемо | — |
| v2 | `round()` | возвращает число | теряет trailing zero (3.1 вместо 3.10) |
| v3 | `format()` | работает везде | устаревший синтаксис |
| v3 | `format()` | работает везде | устаревший |
| v4 | `math.exp(1)` | интересный факт | избыточно |

## Вывод
Для вывода — **v1** (f-строка). Для дальнейших вычислений — **v2** (round).

## Эксперимент: math.e vs math.exp(1)
- `math.e` и `math.exp(1)` дают ИДЕНТИЧНЫЙ float (до последнего знака)
- Разница = 0.0, `==` возвращает True
- Вопреки ожиданиям, `math.e` — не «захардкоженная» константа,
  а результат вычисления C-библиотеки libm
- Вывод: `!r` (repr) показывает float во всей точности — полезно для отладки
