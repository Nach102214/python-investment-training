# Глава 2. Обмен значениями между переменными

## 💡 Классическая аналогия из книги

Как поменять местами содержимое двух чашек (молоко и чай)? Нужна третья чашка.
Для обмена значениями переменных — тот же принцип: нужна временная переменная.

## ❌ Неправильно (потеря значения)

    a = b   # a потеряло своё старое значение!
    b = a   # b = b — ничего не изменилось

## ✅ Три правильных способа

### Способ 1: через временную переменную

    temp = a
    a = b
    b = temp

Работает для любых типов. Универсально и понятно.

### Способ 2: через арифметику (только для чисел)

    a = a + b
    b = a - b
    a = a - b

⚠️ Ломается на строках и float с большими числами.

### Способ 3: через распаковку кортежа (Python-идиома)

    a, b = b, a

Python-стиль. Работает для любых типов. Самая короткая запись.

## 🔄 Циклический сдвиг трёх переменных

Задача: после выполнения b = старое a, c = старое b, a = старое c.

Через temp:
    temp = c
    c = b
    b = a
    a = temp

Через распаковку:
    a, b, c = c, a, b

Порядок в правой части = порядок ПОЛУЧЕНИЯ значений переменными слева.

## 💼 Применение в финансах

- **Своп-сделки** — обмен активами между сторонами.
- **Ребалансировка портфеля** — замена одних бумаг на другие.
- **Очереди ордеров** — циклический сдвиг приоритетов.
